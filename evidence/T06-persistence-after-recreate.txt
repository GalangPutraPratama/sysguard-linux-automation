=== T06: Persistence After Recreate ===

--- Step 1: Add test file ---
$ echo "Persistence test data" > data/source/persist-test.txt

--- Step 2: Verify in container ---
$ docker exec sysguard-nginx cat /usr/share/nginx/html/persist-test.txt
Persistence test data

--- Step 3: Destroy container ---
$ docker compose -f docker/compose.yaml down
✔ Container sysguard-nginx    Removed
✔ Network docker_sysguard-net Removed

--- Step 4: Recreate container ---
$ docker compose -f docker/compose.yaml up -d
✔ Network docker_sysguard-net Created
✔ Container sysguard-nginx    Started

--- Step 5: Verify file survives ---
$ docker exec sysguard-nginx cat /usr/share/nginx/html/persist-test.txt
Persistence test data

=== RESULT: Data persists after container recreate ===

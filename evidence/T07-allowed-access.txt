=== T07: Allowed Secure Access ===

--- SSH Login ---
$ sshpass -p 'project123' ssh -o StrictHostKeyChecking=no -p 2222 sysguard@localhost whoami
sysguard

--- SCP File Transfer ---
$ echo "SCP test file" > /tmp/scp-test.txt
$ sshpass -p 'project123' scp -o StrictHostKeyChecking=no -P 2222 /tmp/scp-test.txt sysguard@localhost:/home/sysguard/
$ sshpass -p 'project123' ssh -o StrictHostKeyChecking=no -p 2222 sysguard@localhost cat /home/sysguard/scp-test.txt
SCP test file

=== RESULT: Allowed user can SSH and transfer files ===
